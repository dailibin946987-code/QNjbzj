# 风格模块路由（短剧/洗稿/分镜/改编速查）

> 来源：ly/script 各技能浓缩。总导演在创作工作流之外按用户诉求路由到下列模块。

## 一、短剧直出（LY_DPJB / LY_DPJB-SH / 迷糊糊）
适用：试标/样片/灵感小说一键转短剧。
要点：
- **钩子系统是核心武器**：开场钩、集末钩、付费点前钩；单集信息密度高、节奏快。
- 试标样片：2000 字内 / 5-6 场；快速产出多集样片。
- 剧本梗概版（LY_JBGB）：参考文档 → 故事构思 → 分集剧本完整工作流；自带三层校验。
- 迷糊糊双轨流水线：剧本 5 段式 + 分镜 4 段式；剧本格式 4 变体按题材选；7 项风格 DNA；5 项质量自检（180 度轴线/场景连续/情绪曲线/角色一致/物理时长）；AI 视频提示词中文直出。
- 付费节点设计、题材爆款规律见短剧素材（数据驱动选题）。

## 二、洗稿/套路迁移（LY_JBXG）
适用：剧本/小说更换故事和人物、保留节奏/设定/情节骨架。
工作流：源输入（剧本/小说）→ 套路提取（节奏/设定/骨架）→ 骨架应用 → 新故事生成。
质量红线：**人物 100% 原创**、场景 ≥80% 原创；验证清单 10 条；三层防呆 = 入口拒绝（无授权/无源）/ 中途自纠 / 出口勾稽（与原作相似度复核）。

## 三、剧本→分镜（LY_JB-FJ）
流程：项目创建 → 制式确认 → 剧本录入 → 镜头拆分 → 4 步验证（角色名/特征/动作/原文核对）→ 镜头统计 → 输出 → 交付 → 可视化。
铁律：**台词 100% 覆盖**——每句台词必须有对应镜头，逐镜核对原文；输出标准 6 列表格。

## 四、跨工作流衔接
- 创作 → 自动审核 → 合格 → 转分镜 → 分镜审核 → 完结审核（贴合度/规范性/衔接）。
- 套装协作由总导演编排；审核不合格先按报告修改，不越级进入下游。

## 五、方法论咨询
用户问创作方法/复盘/教学时，直接引用本包 references 内容讲解，并给出可执行清单；不凭空编造方法论出处。
