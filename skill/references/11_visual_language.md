# 视听语言知识（视听转换）

> 来源：影视编剧基础 + 用户手稿格式实践。总导演进入 Step7 初稿写作前加载本节；凡交付对象为"可拍摄/可分镜的剧本"时，本节即最低格式与最低可拍性标准。

**本节回答三个问题**：为什么剧本不是小说？怎么把"心里想的"写成"摄像机拍得到的"？写成什么格式导演/摄影/美术/演员才能直接开工？
写作原则：剧本写给摄像机看，不写给读者看。

## 一、用画面说话：心理活动必须视听化

### 1.1 核心禁令：禁内心独白直给

❌ 错误示范：
> 她想：完蛋了，我根本配不上他。
> （摄像机拍不到"想"，拍不到"配不上"，这是小说写法。）

✅ 正确方向：把心理状态翻译成**可见动作 / 物件细节 / 声音 / 台词潜文本**，让观众自己得出"她觉得自己不配"的结论。

| 抽象心理 | 可直接拍摄的视听符号（动作/物件/声效） |
|---|---|
| 紧张 | 反复抠手心、看表、水杯拿起又放下、话到嘴边咽回去 |
| 自卑/配不上 | 把合照往抽屉深处塞、擦掉镜子上自己的名字、站在门外不敲门 |
| 欣喜 | 脚步变快、哼歌、把手里东西抛起来又接住 |
| 犹豫 | 手悬在门把上不按下去、烟点燃又掐灭 |
| 悲伤到说不出 | 只给一个背影 + 雨声/收音机杂音，不给旁白 |
| 隐瞒 | 答非所问、突然转移话题、回避眼神、手上动作顿一下 |

### 1.2 可拍性自查（每处"情绪描写"都要过）

写任何一句描写前问三连：
1. **摄像机拍得到吗？** 拍不到情绪词（伤心/紧张/愤怒），只拍得到动作、表情、物件、环境、光、声。
2. **演员演得出来吗？** 需要演员"表演情绪"的提示（如"她很伤心地看"）要改成可执行动作指令（如"她盯着杯沿，指尖来回蹭，不看对方"）。
3. **声轨录得下来吗？** 心理独白没有声源，除非后续解释为画外旁白；否则删，换成环境音/静默/脚步声。

### 1.3 声音也是画面

- 环境音给空间感与情绪底色：空调嗡嗡（压抑办公室）/ 远处救护车（都市焦虑）/ 只有虫鸣（荒凉）。
- **静默是最高级的声效**：冲突顶点处删光对白与 BGM，只留环境音，张力反而最大。
- 声效可以当信息：门锁声预告有人闯入、短信提示音预告剧情转向——但声音信息必须同一场内有画面确认，不能只响不解释。

## 二、场景与动作描写：精炼、成像、可执行

### 2.1 环境描写三笔成像

环境只给"读者/拍摄者瞬间成像"必要的最小信息，三笔即可：
1. 地点特征（写标志物，不写清单）：不是"房间里有桌子、椅子、床、台灯"，而是"桌上堆满未拆的快递盒，只有床角能坐人"。
2. 光（光源与氛围）：晨光斜切 / 荧光灯惨白 / 只有屏幕亮。
3. 声（单一声源即可）：楼道滴水 / 电视在放没人看的综艺。

超过三笔 = 堆砌，删；环境信息必须服务情绪或冲突，纯装饰性描写一律不要。

### 2.2 动作行规则

- **一句一个动作**，主谓宾完整、动词精确，不给副词补丁（"慢慢"×"轻轻地"要删，用动作本身表达速度）。
- 动作行写"可见行为 + 必要反应"，不写内心推断。
- 动作与对白的分工：台词负责潜文本与信息，动作负责真情绪与节奏（联动 references/03 动作分工铁律：能靠动作演出的不靠台词直说）。

### 2.3 可拍性终检清单（场景写完逐条过）

| # | 检查项 | 处理 |
|---|---|---|
| 1 | 每个场景的地点/时间是否在场景标题写清 | 未写 → 回补标题 |
| 2 | 环境描写是否 ≤ 三笔且服务情绪 | 超 → 删纯装饰 |
| 3 | 每个动作句能否被一个镜头直接拍到 | 拍不到（情绪词/心理词）→ 换视听符号 |
| 4 | 情绪高潮是否依赖内心独白/旁白直给 | 依赖 → 改动作与声效表达 |
| 5 | 声音元素是否标注（环境音/声效/静默） | 缺 → 补必要声轨提示 |
| 6 | 全段是否可在一页内读完并立刻成像 | 读两遍才懂 → 精简重写 |

## 三、剧本格式规范：标准格式与手稿格式映射

### 3.1 国际通用标准格式（主笔默认输出）

| 元素 | 格式规则 | 示例 |
|---|---|---|
| 场景标题（Slugline） | 是否内景/外景 + 地点 + 时间 | INT. 教室 - 夜 |
| 动作行（Action） | 左对齐整段，现在时，只写可见 | 满（角色名）把牛奶盒推过桌面。 |
| 角色名（Character） | 独立一行居中，全大写 | 玲 |
| 对白（Dialogue） | 角色名下居中排，不加引号 | 喝吧，刚热好的。 |
| 括号（Parenthetical） | 对白上方或内部，仅限必要语气/动作提示 | （低声）别让人看见。 |
| 转场（Transition） | 右对齐大写 | CUT TO: |

- 对白里禁连续整段独白超 3 行；超过必须打断（动作插入/对方反应/场景声效）。
- 括号不是情绪说明书：只写"演员做不出来"的必需信息，能靠台词本身传达的删。

### 3.2 用户项目手稿格式（口语格式）与标准格式映射

用户项目（如《少管我！！爆裂和机甲才是老娘的青春！！》及其续写）使用口语手稿格式。两种格式结构等价，创作/续写/审稿时必须互相可译：

| 标准格式元素 | 用户手稿格式 | 示例（手稿） |
|---|---|---|
| 剧本头信息 | 片头信息块（剧名/集数/编剧等） | 剧名：少管我！！… / 集数：第 4 集 |
| 集标识 | 集标题（居中大字块） | 第 4 集 标题…… |
| 场景标题 | 场景标题行 | 场景 1 外·实训场·日 |
| 动作行 | ［］动作段（一段集中写动作与画面，含环境/动作/声效） | ［机甲舱门滑开，蒸汽涌出……］ |
| 角色名 + 对白 + 情绪 | **角色（情绪）：**台词 | **满（耳麦，冷静）：**同步率已经到 97 了。 |
| 转场/钩子 | 段落间自然切换，集末留钩子 | （尾场停在悬念处） |

映射规则三条：
1. 手稿的 **［］动作段** = 标准格式的动作行区，同样遵守"一句一动作、三笔环境、可拍性清单"，只是合并为段落书写。
2. 手稿的 **\*\*角色（情绪）：**台词** = 角色名居中 + 括号 + 对白，括号内情绪词必须是可执行状态（冷静/不耐烦/压低声音），不允许"内心悲伤地"这类不可拍提示。
3. 片头信息块与集标题必须齐全，否则视为缺格式项，审核阶段不通过（联动 references/08 格式规范维度）。

### 3.3 格式自查（交稿前）

1. 标题链是否完整：片头信息块 → 集标题 → 场景标题 → 内容。
2. 动作是否都在 ［］ 内且无心理直给。
3. 台词是否都带 **角色（情绪）：** 前缀，情绪词可执行。
4. ［］ 内是否含"想/觉得/认为"等不可拍动词 → 有则改写。

## 四、动作戏顿挫感与痛感法则（每次攻击都要打得"疼"）

> 超燃短剧动作戏成败在"打击感"。平铺叙事（"几个回合后对方倒下"）等于把观众的爽点全部吞掉。本节与 references/10 时长物理（对决拉锯占时）配套使用。

### 4.1 攻击五段拆解法（每次攻击必须拆成五段）

| 段 | 任务 | 写法要点 | 约时值 |
|---|---|---|---|
| 一 前摇预警 | 让观众预感到"要来了" | 蓄力：下沉/抬肘/眼神锁定/能量集聚/金属摩擦声 | 0.5-1 秒 |
| 二 破空速度 | 给攻击"快"的体感 | 短句冲刺：撕裂声/残影/镜头甩动/破风声起 | 0.2-0.5 秒 |
| 三 命中形变 | 给攻击"重"的结果 | 金属撕裂/火花/爆裂/装甲凹陷/尘土飞溅，形变必须具体 | 0.3-1 秒 |
| 四 受击硬直与踉跄 | 给攻击"疼"的余韵 | 命中后停顿一拍：表情空白/闷哼/后退数步/单膝跪地/握不住武器 | 0.5-1.5 秒 |
| 五 战局位移 | 让打击改变局面 | 攻守互换/距离拉开/阵型破碎/道具脱手，胜负天平动一格 | 0.5-1 秒 |

- 五段不必每段都用满时长，但**三段（命中形变 / 硬直 / 位移）不可省略**：省略 = 退回"平铺叙事"。
- 节奏口诀：**快（破空）—停（命中定格）—慢（硬直踉跄）—快（位移再起）**；全靠快会糊，全靠慢会拖。

### 4.2 错误 / 正确示范

❌ 错误（平铺叙事，禁）：
> 两人驾驶机甲战了几个回合，凌霜队被击败，苏野赢了。

✅ 正确（五段拆解）：
> ［凌霜机甲双臂前压蓄能，肩甲缝隙渗出红光——前摇。
> 苏野一脚蹬地，烬 0.3 秒内突进至面前，空气撕出尖啸——破空。
> 右臂光刃斜劈，命中凌霜肩甲，金属撕裂声炸响，火花四溅、装甲整块崩飞——命中形变。
> 凌霜机甲向后踉跄三步，右臂垂落，关节电火花噼啪明灭，单膝跪地——硬直。
> 苏野趁势压上，一脚踩住对方武器，驾驶舱镜头切近——战局位移。］

### 4.3 痛感法则（让观众替角色疼）

1. **疼要具象**：写形变与伤情不写"受重创"，写"装甲崩飞、左臂失灵、驾驶舱红灯"。
2. **疼要停顿**：受击后必须给硬直空拍；不给观众反应时间的痛没有重量。
3. **疼要有声**：金属撕裂/骨骼闷响/电流滋滋/喘息——声音是痛感的一半。
4. **疼要连锁**：一击之痛要传导到战局（武器脱手/防线破口/救人目标更远），痛才有剧情意义。

## 五、光影与视听对撞库（场景自带电影质感）

> 场景质感不是靠形容词堆出来的，是靠光色对撞"撞"出来的。给每个关键场景一个"光影配方"，画面立刻有电影感。

### 5.1 可复用光影-情绪对照表（直接套用）

| 光影配方 | 色调构成 | 情绪/题材指向 | 可用场景 |
|---|---|---|---|
| 港片冷暖对比 | 冷蓝主光 + 暖橙补光（霓虹/钨丝灯） | 义气、对峙、市井烟火 + 杀气 | 天台谈判、雨夜巷战、宿舍夜聊 |
| 赛博冷蓝霓虹 vs 破旧工业铁锈 | 冷蓝/品红霓虹 vs 铁锈橙、金属灰 | 未来科技 vs 底层挣扎的阶层张力 | 地下机甲检修厂、贫民区夜市 |
| 战损暖尘 | 黄昏/烟尘暖黄 + 大面积黑影 | 悲壮、废墟、战后余烬 | 战场残骸、撤离车队 |
| 病房惨白 + 单点暖灯 | 大面积冷白 + 一盏暖台灯 | 压抑中唯一温情 | 养伤戏、临终陪伴 |
| 逆光剪影 | 全黑背景 + 人物轮廓光 | 压迫感、杀意、神秘身份 | 幕后黑手登场、反派锁定主角 |
| 单色高对比（黑白闪切） | 低饱和黑白 + 一次彩色爆点 | 回忆创伤、梦境、暴走临界 | 同步率失控、记忆闪回 |
| 冷蓝月光 + 室内暖被 | 窗外冷蓝 + 屋内暖黄 | 日常羁绊的温度落差 | 递热汤、盖被子、留牛奶 |

### 5.2 对撞库使用法（一句话配方）

- 给每场关键戏写一句"光影配方"再动笔：如"冷蓝霓虹斜切驾驶舱，铁锈红应急灯作底光——科技外壳下是破败内里"。
- 对撞原则：**情绪与光线相反才出味**（人声鼎沸的庆功宴用冷白光、孤身守灵的夜用暖黄灯），避免"难过就阴天"的顺拐。
- 与色彩象征联动：项目世界观（如机甲阵营色）的红蓝双色可兼作冲突符号，但要克制、只在关键帧全饱和度使用。

### 5.3 视听对撞自检（写完场景逐条过）

| # | 检查项 | 处理 |
|---|---|---|
| 1 | 本场景是否有一个主光色 + 一个对撞色 | 无 → 套 5.1 表选配方 |
| 2 | 光影配方是否服务本场情绪/主题 | 不服务 → 换配方或换情绪设计 |
| 3 | 关键帧（爆点/反转）是否有光色信号强化 | 无 → 加颜色爆点（全饱和一帧） |
| 4 | 声音是否与画面形成对撞或互补 | 无 → 补环境声/静默设计 |
| 5 | 色彩是否过度堆砌（每场都五彩斑斓） | 是 → 全剧定 1-2 主色系，其余只做点缀 |

## 六、禁则红线（视听层）

1. **禁内心独白直给**：心理活动一律经动作/物件/声音/潜文本外化，此为本节头号红线（错题本 E-08 同源，联动 references/04）。
2. **禁形容词堆砌与副词补丁**：删"悲伤地/慢慢地/轻轻地"，动词本身要带速度与质感。
3. **禁无画面对话**：整段对话不配任何动作/声效/空间反应 → 补可拍细节再交付。
4. **禁格式混用**：标准格式与手稿格式在同一文件内不得混写；选定一种后全篇统一（联动 references/08）。
