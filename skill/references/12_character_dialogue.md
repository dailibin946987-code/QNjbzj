# 人物与对白知识（血肉填充）

> 来源：人物弧光理论 + LY 台词引擎实践 + 用户续写项目经验。总导演进入 Step3 人物小传前加载本节；**任何续写任务必读本节**（第三部分为续写铁律）。

**本节回答三个问题**：人物为什么这么选（动机）？这个人怎么一开口就是他（台词）？续写为什么不是套模板而是让故事长出来（铁律）？

## 一、人物动机工程：动机要能解释每一次选择

### 1.1 动机三件套（写小传必填）

| 层 | 定义 | 作用 | 示例（玲） |
|---|---|---|---|
| 表层目标 | 人物在剧情中追着要的东西 | 驱动外部情节 | 成为独立支援机师、考上正式席位 |
| 底层需求 | 目标背后真正缺失/渴望的东西 | 驱动深层选择 | 被认可为"有用的人"，不再只是被照顾的对象 |
| 核心恐惧 | 人物最怕失去/面对的东西 | 设定行为边界 | 怕被当累赘、怕给人添麻烦（所以总把话咽回去） |

- 表层目标负责"故事在推进"，底层需求负责"选择有深意"，核心恐惧负责"他什么时候会退缩"。
- 阻碍同样分内外：外部阻碍（对手/环境/规则）给他行动压力，内部阻碍（恐惧/盲区/旧伤）给他行动变扭；人物成长的本质是"内部阻碍被外部事件逼到台前并跨过去"。

### 1.2 动机-选择测试法（每次关键选择前问）

人物在每个关键节点做出选择时，主笔必须能通过测试：
1. 这个选择是否由他的表层目标 + 底层需求 + 核心恐惧共同推出？（缺一个 = 动机不全）
2. 换一个完全不同的人设，在同样处境会不会做出同样选择？（会 = 选择没人物特色，动机写废了）
3. 有没有更省事的选项被人物主动放弃？放弃的理由是否来自他的核心恐惧？（能答出 = 动机立得住）

### 1.3 实操：人物动机卡（Step3 每角色一张）

| 字段 | 填写 |
|---|---|
| 角色名 / 一句话定位 | 玲：内向害羞、外柔内刚的插班支援机师 |
| 表层目标 + 时限 | 三个月内通过独立机师实操考核 |
| 底层需求 | 证明自己不是"被保护的人"，而是能并肩的人 |
| 核心恐惧（及其来源） | 怕拖累队友 → 源自旧队伍一次因她失误的失败 |
| 外部阻碍 | 考核规则苛刻 / 苏野同步率碾压式对比 |
| 内部阻碍 | 不敢开口求助，遇事先硬扛 |
| 行为签名（3 个标志性习惯） | 递东西不直视对方 / 紧张时捏耳垂 / 说"没关系"频率高 |
| 弧光终点（从哪到哪） | 从"独自硬扛"到"敢把后背交给队友" |

## 二、个性化台词：身份决定语域，潜台词决定深度

### 2.1 台词身份三件套（每句台词都要过）

1. **出身/阶层**：用词、句长、讲不讲礼貌用语——大小姐和孤儿出身不可能同一套说法。
2. **职业/专业域**：机师开口带参数、带数据流；医生开口先问症状；台词里的职业词汇是人物可信度的速写。
3. **关系亲疏**：对上级/同级/在意的人，称呼、语气、句长都会变；角色对所有人都一个腔调 = 人物没写出来。

**换人检验（终极）**：把任意一句台词遮住角色名读一遍——如果换成另一个角色也成立，这句台词就失败了（联动 references/03 台词引擎十要十不要）。

### 2.2 潜台词（Subtext）：嘴上说的 ≠ 心里想的

潜台词七法（每场对白至少用 1 种，禁止全场直球对白）：

| 手法 | 说明 | 例（玲对苏野） |
|---|---|---|
| 话反说 | 用反话表达真意 | "谁要你教啊"（实际想要他教） |
| 不答反问 | 避开问题，反问对方 | "你呢？不也半夜在这练" |
| 留白 | 话说到一半掐断 | "我只是……算了。" |
| 转移话题 | 不想面对就岔开 | 被问到心事 → "这牛奶再不喝要凉了" |
| 物件代替 | 用动作/物品传情 | 把牛奶推过去，不看他 |
| 沉默 | 不说本身是回答 | 追问 → 低头捏衣角 |
| 肢体抢先 | 动作先于语言背叛内心 | 嘴上说没事，手在抖 |

### 2.3 禁假大空说教（五查）

| # | 自查 | 通过标准 |
|---|---|---|
| 1 | 删口号 | 台词里没有可直接当海报的漂亮话 |
| 2 | 删总结性独白 | 没有"其实我们都是为了……"这类替观众总结的段落 |
| 3 | 查主题出口 | 主题靠选择与行为落地，不靠角色说出来（联动 references/10 节拍为主题服务） |
| 4 | 查信息倾倒 | 长台词每超 3 行必有打断/动作/反应 |
| 5 | 查教育腔 | 没有"你要明白……你必须……"式对观众讲课的句子 |

## 三、续写铁律（用户强调重点）：续写是让故事继续合理生长，不是套模板

### 3.1 续写的底层定义

- 续写 = 在既有**人设、世界观、前情因果**约束下，让角色按自己的动机做出下一步，碰撞出新事件。
- 续写 ≠ 把上集钩子机械解掉、更 ≠ 把热门桥段按格式重填一遍。
- 一句话判据：**这一集不是"编剧想要它发生"，而是"按这些人的性子，到了这一步，它只能这么发生"。**

### 3.2 四条续写铁律

**铁律一：人物行为必须由动机与前情因果推出**
- 每个新动作/新选择，都要能从角色动机卡 + 前情事件链中推导；推导不出来 = 人物被剧情绑架，必须回炉。
- 前情里欠的账要还（上集埋的伤、放的话、欠的人情），续写优先收前账，再开新账。

**铁律二：新剧情不得违背已立人设与世界观**
- 人设红线（纯友谊边界、性格底色、能力上限）和世界观规则（机甲参数、体系设定、力量代价）是硬约束；新增设定只允许补充解释，不允许推翻前文。
- 若要推动角色成长，写"他跨过了自己的恐惧"，不写"他忽然变成另一个人"。

**铁律三：情感与转折必须有铺垫来处**
- 任何情感爆发（哭/怒/告白/决裂）与情节转折（反杀/真相/回归）在本集或前集必须有至少一个可见伏笔或情绪积累点。
- 禁止空降情绪：角色突然崩溃却没有来处 = 错题本级错误（联动 references/04 E-01~E-13 防回退）。

**铁律四：新信息只能生长，不能改写**
- 续写可补充背景（回忆、细节、世界观扩展），但不得改写已交付集数的既定事实；确需修正时按"新条目 + 状态标记"走记忆协议（联动 references/05），并在交付说明中明示。

### 3.3 续写前核查清单（动笔前与交稿前各过一遍）

| # | 核查项 | 说明 |
|---|---|---|
| 1 | 本集核心事件是否由上一集钩子 + 人物动机自然接出 | 是 → 继续；否 → 回 3.2 铁律一 |
| 2 | 出场角色的动机卡是否在手边且未偏离 | 偏离 → 先修动机卡再写 |
| 3 | 新剧情是否引入新人物/新设定 | 引入 → 检查是否违背世界观、动机是否完整 |
| 4 | 本集情感爆发点是否有铺垫来处 | 无 → 补前情积累或删爆发 |
| 5 | 是否兑现了前情承诺（台词/伏笔/关系线） | 有欠账 → 优先在本集或下集安排偿还 |
| 6 | 人设红线清单是否逐条过（尤其纯友谊/禁性化类红线） | 违线 → 立即改写 |
| 7 | 每句关键台词是否过"换人检验 + 潜台词检验" | 不过 → 回第二部分改写 |
| 8 | 格式是否与既有集数完全一致（片头/集标题/［］动作段/**角色（情绪）：**台词） | 不一致 → 回 references/11 格式映射修正 |
| 9 | 结尾钩子是否为下一集留出"非写不可"的势能 | 没留 → 重设集末钩 |
| 10 | 全稿过监察（错题本断言 + 审美门控） | 未过 → 回炉至多 2 轮后交付（联动 references/01 与 references/08） |

## 四、禁则红线（人物层）

1. **禁工具人化**：任何角色不得只为推动剧情而存在，至少要有动机卡一行以上的底色（短剧龙套除外，但须有明确功能标签）。
2. **禁人设漂移**：为剧情服务临时改性格、改说话方式 = 高优先级回炉项。
3. **禁直给主题与直给情绪**：动机、情感、主题一律经选择/行动/潜文本表达，禁内心独白直给（联动 references/11）。
4. **禁续写套模板**：任何"上集钩子 + 通用桥段"式拼接必须按 3.3 清单逐条核查后才可保留。
