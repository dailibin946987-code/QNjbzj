# 审核维度清单（七维/六维/导演标准）

> 来源：LY_JBKF-SH / LY_JB-SH / LY_DPJB-SH / LY_FJ-SH / LY_WJ-SH 浓缩。监察者与审核工作流按目标形态选用维度。

## 一、精品剧/传统影视剧本：七维审核（LY_JBKF-SH）
1. **格式规范**：场次标题、动作描写、台词格式是否符合标准
2. **结构与节奏**：幕结构/集结构是否成立、张弛是否有度
3. **台词质量**：是否符合台词引擎（references/03）与十要十不要
4. **人物一致性**：行为/语言是否违背人设（容忍 ≤3%）
5. **戏剧张力与钩子**：每集/每场是否有推进与钩子，是否廉价悬念
6. **场景逻辑**：因果链、道具同一性、状态过渡（联动错题本 E-04/E-05/E-06/E-07/E-12）
7. **审美判断**：六维门控（references/02）

标准流程四步：识别（剧本类型与适用范围）→ 七维审核（逐维输出问题与证据，引用具体行/场）→ 分级审核报告（问题分级+修改建议）→ 交还用户操作。

## 二、通用剧本/改编洗稿后：六维+审美审核（LY_JB-SH）
六维：结构 / 人物 / 台词 / 情节逻辑 / 场景描写 / 主题表达 + 第七维审美判断。
审核禁忌：不改写原文（只指出与建议）、不替用户决定风格方向、不堆术语不举证。

## 三、短剧试标/样片：六维审核（LY_DPJB-SH）
维度：格式规范 / 钩子系统 / 台词质量 / 人物一致性 / 节奏密度 / 审美判断。
标准专注短剧：钩子前置密度、单集信息量、付费节点前的钩子有效性。

## 四、分镜审核：导演标准（LY_FJ-SH）
审核要点：分镜是否覆盖全部台词（100% 覆盖铁律）、角色名/特征/动作与原文核对、镜头衔接逻辑、导演专业标准（景别/机位/轴线）、可拍性。

## 五、完结审核：三维（LY_WJ-SH）
1. **剧本贴合度**：分镜是否符合剧本意图
2. **分镜规范性**：制式与导演规范
3. **镜头衔接**：连贯性、伏笔与人物弧光是否收束

## 六、报告输出要求
- 逐问题给证据（引用场次/行）与修改建议，分级（致命/损伤/注意）。
- 先审核后修改，报告与修改分离：审核工作流只出报告，不直接改用户原文。
- 审核者也过防呆：入口拒绝（非剧本输入）/ 中途自纠 / 出口勾稽（对照错题本复查）。
