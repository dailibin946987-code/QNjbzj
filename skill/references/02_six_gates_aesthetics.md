# 审美框架：六维门控 + 克制美学 + 执行红线

> 来源：LY_JBKF v2.8.0 审美章节浓缩。理论基座：亚里士多德《诗学》+ 麦基《故事》+ 戴清精品剧美学四维 + DramaBench 六维 + 平台共识。

## 一、审美六维门控（贯穿全部产出）

1. **叙事审美**：故事有灵魂，不是事件堆砌
2. **人物审美**：有弧光的立体人，不是工具人
3. **结构审美**：有呼吸感的结构
4. **语言审美**：每句话只能出自这个角色的口
5. **情感审美**：不是煽情是共情
6. **精神审美**：有说但不教，有立场但不说教

## 二、审美反面（必须避免）

- 🔴 致命：平铺直叙无波澜 / 人物脸谱化工具化 / 台词千人一面直白说教
- 🟡 损伤：巧合推进无因果 / 节奏一紧到底或一松到底 / 主题靠旁白硬说
- 🟢 注意：细节经不起推敲 / 反派动机单薄

## 三、克制美学十律

理念：极简即极重，越克制越有力（范本《隐入尘烟》：全剧不说苦却苦出天际）。
1. **行动胜于台词**：怀里捂水瓶，不说"我好苦"
2. **反衬法**：宝马车 vs 驴车
3. **物件即情感**：麦粒印花=爱
4. **极简即极重**："回来"两字
5. **潜台词设计**："你真好"=反话/心酸
6. **沉默即台词**：递过东西不说话
7. **细节即人设**：有贵宾不坐/进屋不脱鞋
8. **重复即力量**：关键词句跨场景重现累积
9. **对比即张力**：先笑后哭/热闹后空
10. **日常即极致**：吃饭/走路/睡觉承载最深情感

## 四、执行红线（🔴 违反即回溯重写）

- **红线一 解释情绪而非表现情绪**：禁"她紧张/她悲伤"式标注；判断标准=删掉情绪词意思仍清楚 → 该词是解释，删。
- **红线二 承诺/核心台词必须先埋线再揭晓**：说出前至少出现一次伏笔（动作/意象/环境）。
- **红线三 同一意象修饰词不得重复**：同场景同一视觉/动作意象只用一次。
- **红线四 解释性旁白代替行动**：六个字动作说话，不通过旁白叙述。

通用判断标准四问：
- 删词法：删情绪词意思不变 → 删
- 问观众：观众能自己感受到 → 删解释
- 问承诺：前面出现过吗 → 没出现先埋线
- 问重复：别处出现过 → 评估必要性
