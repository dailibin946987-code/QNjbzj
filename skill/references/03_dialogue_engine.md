# 台词引擎：四大哲学 + 逻辑控制 + 十要十不要

> 来源：LY_JBKF v2.8.0 台词生成引擎 v2.0 浓缩。核心：抛弃概率接龙，严格遵循戏剧因果律。

## 一、台词设计四大哲学
1. **潜台词与心理博弈**：冰山理论——说出口 1/8，暗流 7/8；观众享受听懂弦外之音。
2. **极度的真实感与在地性**：台词从特定人物嘴里"长"出来；方言/职业语制造真实感。
3. **台词即动作**：台词是武器——攻击/防御/试探/安抚/隐瞒，每句推动关系或剧情。
4. **留白与视听协同**：光影/微表情已烘托到位时台词隐退，为画面呼吸感留空间。

## 二、逻辑控制内核（生成前必过）
1. **结构锚定**：输出前声明【起始情绪价值】与【终点情绪价值】，台词服务于状态转变。
2. **动机隔离**：每角色分配表层目的 + 底层隐蔽动机；台词只展现表层，绝不直接暴露 Hidden_Motive。
3. **动作性输出**：严禁水台词；每句带 Action Tag（刺探/掩饰/攻击/防御/转移/安抚等）。

输入必含：Scene_Environment / Value_Shift[起始A→终点B] / Character_A/B(Profile+Surface_Objective+Hidden_Motive) / Beat_Limit（节拍数而非回合数）。

## 三、三步验证
- Step1 节拍推演：静默推演互动逻辑链，逼近 Value_Shift。
- Step2 潜台词校验：**强校验**——台词若直接暴露隐蔽动机，触发错误立即重写。校验公式：提取表层意思 → 检查是否暴露隐蔽动机 → 是则重写 / 否则通过。
- Step3 文本输出。

## 四、台词十要十不要
十要：有目的 / 有延续（接住上句）/ 有对象（说给特定人听）/ 有冲突 / 有潜台词 / 口语化 / 可打断 / 有新信息 / 有关键词句（钩子）/ 是角色自己的话。
十不要：直白说中心思 / 零碎无指向 / 重复已说信息 / 冗长超 3 行 / 雷同腔调 / 呆板书面化 / 过于内省自白 / 前后不连贯 / 虚假煽情 / 矫情文艺腔。

**终极检验：台词换给另一角色也成立 = 失败台词。**

## 五、台词与动作的分工铁律
- 动作已完成 → 台词让位（见错题本 E-08）。
- 情感在动作里，不在台词里（克制美学律一）。
- 谁走谁留谁等谁 → 主语必须清晰（错题本 E-11）。
