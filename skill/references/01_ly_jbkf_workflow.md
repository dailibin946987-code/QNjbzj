# 七步创作流水线（精品剧/电影/迷你剧/长剧）

> 来源：LY_JBKF v2.8.0 方法论浓缩。主笔创作必须逐步执行、逐步过门控；任一门控不通过即回溯修改，严禁跳步交付。

## 总览

| 步骤 | 产出 | 门控 |
|---|---|---|
| Step1 故事创意 | Logline | ①创意审美 |
| Step2 故事梗概 | 1000-3000 字 | ②叙事审美 |
| Step3 人物小传 | 灵魂画像（分级） | ③人物审美 |
| Step4 故事大纲 | 幕结构+事件链 | ④结构审美 |
| Step5 分集大纲 | 每集核心事件+悬念 | ⑤节奏审美 |
| Step6 分场大纲 | 每场功能+状态 | ⑥场景审美 |
| Step7 初稿写作 | 完整剧本 | 终审⑦ |

## Step1 故事创意
交互确认四要素：①目标形态（电影 90-120 分钟 / 迷你剧 6-12 集 / 长剧 24-40 集）②题材类型 ③核心情感 ④灵感来源。
Logline 句式：`[主角]是[身份/处境]，为了[目标/欲望]，面对[核心障碍/对手]，必须[选择/代价]，否则[最坏结果]。`
**门控①创意审美**：视觉感 / 独特性 / 情感锚 / 冲突度 / 立意感 全通过进下一步；任一 ❌ 重新构思。

## Step2 故事梗概
必含：故事全貌 / 核心冲突 / 人物关系 / 情感走向 / 主题立意。
审美要求：不堆砌事件讲情感；转折"没想到但合理"；有呼吸感与留白。
**门控②叙事审美**：故事完整性 / 冲突层次（外部+内部）/ 情感曲线 / 转折因果 / 主题自然 / 余味。

## Step3 人物小传
分级：A 主角+核心配角 3-5 人完整小传；B 重要配角精简；C 功能角色一句话。
A 级四维：
- 静态维度：基础信息 / 前史 / 社会关系
- 动态维度：外在目标 / 内在需求 / 核心恐惧 / 行为模式
- 关系本质：本质 ≠ 表层（表面敌对背后依恋等）
- 人物弧光：正向 / 平坦 / 负向 / 交错；**弧光必须有代价**。
**门控③人物审美**：立体感 / 独特性（互换台词出戏否）/ 关系张力 / 弧光有代价 / 行为一致性 / 潜台词空间。

## Step4 故事大纲
按幕结构：
- 电影：三幕+节拍表，25%/50%/25%，开场 3 分钟钩住观众
- 迷你剧：紧凑三幕（6 集：激励事件第 2 集 / 中点第 4 集 / 高潮第 6 集；12 集：2-3 / 6 / 10-11）
- 长剧：四幕五幕（24 集：激励第 3 集、转折第 8、最大危机 14-15、高潮 20-22）
每幕写清：起点 / 事件链 / 转折 / 终点 / 观众情绪。
**门控④结构审美**：激励事件 / 中点反转 / 最大危机 / 因果链 / 张弛节奏 / 情绪曲线 / 余味设计。

## Step5 分集大纲
每集 200-400 字四件事：开场状态 / 核心事件 / 结尾悬念 / 线归属。
黄金节奏律：**要紧张先有松弛，要悲痛先有喜乐，要爆发先有沉默**。
禁止：集集高潮 / 连续 3 集平淡 / 廉价悬念（靠切断场景冒充钩子）。
多线编排：A 主线 60-80% 每集推进 / B 情感 10-20%（不超 5 集不出现）/ C 悬念 5-15% 精准释放 / D 主题穿插。
**审美铁律：支线必须推动主线；独立支线 = 冗余 = 降级。**
**门控⑤节奏审美**：每集有推进 / 集末有钩子 / 张弛交替 / 支线服务主线 / 信息密度。

## Step6 分场大纲
每场字段：场号 / 时空 / 人物 / 功能 / 开始状态 / 结束状态 / 线归属 / 关键动作与台词方向。
**每场必须有变化**（信息/关系/情感/认知/局势 五类之一）；"开始=结束"的场不该存在。
场景五功能（至少一种）：推进情节 / 深化人物 / 制造悬念 / 营造氛围 / 埋伏笔。
**门控⑥场景审美**：每场有变化 / 可视化 / 因果驱动 / 信息释放 / 人物行动而非解释。

## Step7 初稿写作
原则：先完成再完善；写不出用 `[待补充]` 标记；每写完一集快速自检。
格式：
- 场次标题：`第X场 时间 内/外 地点`（如 `第一场 夜 内 陆家老宅·书房`）
- 每场首行人物说明；动作描写以 `▲` 开头、每行一个动作
- 动作描写四要求：可视化（"攥紧衣角"非"感到不安"）/ 感官化 / 具体化 / 以动写情
台词见 references/03（十要十不要 + 终极检验）。

## 终审门控⑦（量化）
| 维度 | 标准 |
|---|---|
| 叙事效率 | 冗余场景 ≤5% |
| 人物一致性 | 违背人设 ≤3% |
| 情感深度 | 复合情感（如苦笑）≥30% |
| 逻辑一致性 | 逻辑错误 = 0 |
| 冲突处理 | 冲突停滞 ≤2 集 |
| 精神审美 | 主题通过行动和选择自然呈现，不说教 |

全部通过 → 交付；有 ❌ → 定位问题回溯对应层级。

## 五层修改法
结构 → 人物 → 场景 → 台词 → 格式（逐层审查对应审美重点，禁止倒序只修台词掩盖结构病）。

## 降级策略（信息不足时）
1 完整七步 → 2 创意降级（仅创意/人物/结构）→ 3 审美降级（现有剧本求提升：诊断+导演风格建议+修改方案）→ 4 流程降级（方法论指引+模板）→ 5 最小交付（精品剧标准文档，保证有用参考）。**严禁跳过门控或交付不合格内容。**
