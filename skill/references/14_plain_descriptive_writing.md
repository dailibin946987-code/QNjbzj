# 白描与反 AI 味协议（叙述语言层）

> 来源：LY_AI Studio 实战审核案例（2026-09，《半个我》项目 Step1-3 v0.1 被用户判定"AI 味太重"后沉淀）。本协议管"叙述语言"，与 02 克制美学、11 视听语言同属文风层：02 管"不解释情绪"（删情绪词），本协议管"作者退场"（删作者腔）。两者叠加使用，交付前与 04 一并扫描。

## 一、一句话定义

**白描不是"少写一点"，是换人干活：让名词和动词干活，形容词和副词下岗；作者闭嘴，不下判断、不点题、不总结，只把"看见什么、发生什么"如实摆出来，让读者自己得出结论。**

## 二、四句可操作规则

1. **写具体，不写概括**。"每天笑八小时"是概括；右下角计时器跳到 08:00:00、他嘴角已经僵了还得咧着，是白描。
2. **动作替情绪/判断**。"舍不得扔"是判断；他每年把收音机拆开一次、零件擦干净、再装回去、装好也不开，是白描。
3. **作者退场**。金句=作者张嘴替读者下结论；白描把嘴闭上，结论让读者自己砸出来。删除一切"点题句""总结对仗""机锋梗"。
4. **允许毛边**。不是每句都得通往主题；真人写作有笨拙、有闲笔。全程"顺"、句句为情节服务=加工痕迹=AI 味。

## 三、AI 味病句诊断清单（命中即按右栏处理）

| # | AI 味模式 | 典型特征 | 处理 |
|---|---|---|---|
| A-1 | 作者替世界立规矩 | "人们打招呼不问吃没吃，问：这月租出去几个自己？"——用对仗抖机灵概括全城风俗 | 删概括，改具体场景：只写一个人怎么问（闸机口老王隔着人群喊话），不交代"全城皆如此" |
| A-2 | 万能胶水句塞设定 | "没人知道他十七岁那年……""原来/其实/殊不知" | 删胶水句，直接切那年那晚的具体画面 |
| A-3 | 总结对仗金句 | "债是还清了，人还欠着。""他不是 X，他是 Y" | 整句删除，用行动让读者自己咂摸（他一个人坐回关门七年的修车行门口抽烟） |
| A-4 | 档案式介绍人 | "他有个本事：十七种假笑分毫不差" | 不定性，写他干活的具体时刻（工位一面镜子，他对着镜子一遍遍提嘴角） |
| A-5 | 成语/四字概括 | "花光积蓄""流落街头""心如死灰" | 拆成可拍的事实与动作；实在要留，全篇限量 |
| A-6 | 解释性收尾 | "也舍不得扔""说明他还是在乎的" | 删判断，让前面的事实自己说话；读者自己会疼 |
| A-7 | 装饰性开场布景 | "雨落到霓虹招牌上就变色"式环境空镜定基调 | 第一句直接给人/事/冲突；氛围靠后面顺带长出来，不铺陈 |
| A-8 | 情绪词直给 | "他心情沉重""她感动极了" | 联动 02 红线一：删词法处理 |
| A-9 | 句句通主题 | 每段都往"人性/孤独/时代"上收 | 允许有一两段纯粹是日子本身，不升华 |

## 四、判断标准四问（写完一段自问）

1. 这段里作者跳出来说话了吗？（下了判断/点了题/总结了道理 → 删）
2. 删掉形容词和副词，意思还在吗？（在 → 全删）
3. 有没有哪句在"给读者上课"？（有 → 改成人物之间的争夺与动作）
4. 读起来太顺、太工整了吗？（太顺 → 打断节奏，掺一个笨拙的细节）

## 五、错误 / 正确示范（来自实战案例）

❌ AI 味（原稿）：
> 同事之间打招呼不问吃没吃，问：这月租出去几个自己？……同事们佩服他情绪管理好，没人知道他十七岁那年就把"会难过的自己"删了。……债是还清了，人还欠着。他住在城中村顶楼，床脚压一台坏收音机，父亲留下的。他修了七年没修好，也舍不得扔。

✅ 白描（改稿方向）：
> 闸机口，老王隔着三个人冲他喊："阿拾！这月租出去几个？"他伸两根手指。老王乐了："我仨，月底了，留点自己过年。"
>
> 十七岁那年，他爸死在修车行。人抬出来的时候，他在走廊站了一夜，没哭。第二天他找了个做剥离术的，把会难过那部分切了。手术费分十年还。钱还完那天他请了顿火锅，吃完一个人走回修车行门口——门早关了，门口那盏灯还亮着，没人关。
>
> 出租屋在城中村顶楼。床脚压着一台收音机，坏了七年。他每年拆开一次，零件摊一地，擦干净，再装回去，装好也不开。

改稿逻辑：删"全城风俗"只留一个人怎么问；删"没人知道"直接切现场；删金句"人还欠着"换成修车行门口那盏没人关的灯；删"舍不得扔"保留"每年拆开一次、装好也不开"。

## 六、禁则红线（文风层）

1. 禁对仗句、排比句收束段落；金句让读者说，作者不说。
2. 禁"没人知道/原来/其实/殊不知/就这样"类叙事胶水。
3. 禁以"本段点题"为目标的写作；主题只能从行动和选择里长出来。
4. 禁连续两处以上"不是 A，是 B"句式。
5. 同一段内形容词不超过必要值；能用动词名词说清，绝不上形容词。
