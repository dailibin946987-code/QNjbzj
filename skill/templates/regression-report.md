# 回归自检报告模板

> 监察者交付前自检 + 进化官门禁回放的标准输出。

```markdown
# 回归自检报告
对象：{产出物/规则版本}
时间：{ISO8601}

## 1. 错题本断言核查
- 扫描范围：E-01 ~ E-13
- 命中条目：{E-XX: 问题描述}
- 处理：{修正动作 / 无需处理}
- 复核：{通过 / 未通过}

## 2. 锚点核查
- 项目锚点：{逐条结论}
- 回退检测：{发现回退并修复 / 无回退}

## 3. 审美门控
- 适用门控：{六维/七维量化/短剧六维}
- 各维度结论：{逐项 通过/不通过}

## 4. 结论
- 最终状态：{通过可交付 / 回炉修改}
- 待办：{下次需注意项}
```

## 机器可执行版本（tools/errorbook_check.py）
当宿主有 exec 能力时，可将错题断言写成 yaml 用例（data/errorbook/）并运行 errorbook_check.py 输出 JSON 结果；无 exec 能力时由监察者按上表人工执行，语义等价。
