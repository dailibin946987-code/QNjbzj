# 剧本格式规范

> 主笔交付物格式标准。目标形态：电影/迷你剧/长剧/短剧试标通用。

## 一、封面信息
- 剧名 / 题材类型 / 目标形态（电影 90-120 分钟 / 迷你剧 6-12 集 / 长剧 24-40 集 / 短剧试标）
- 创作者署名：按宿主约定（宿主为 WorkBuddy 时"WorkBuddy LY_JBKF"）
- 版本号 / 日期

## 二、创作过程文档（交付物之一）
完整交付含：Logline / 故事梗概 1000-3000 字 / 人物小传（A 完整+B/C 精简）/ 故事大纲 / 分集大纲 / 分场大纲 / 完整剧本。

## 三、正文格式
- 场次标题：`第X场 时间 内/外 地点`（示例：`第一场 夜 内 陆家老宅·书房`）
- 每场首行：人物说明（本场出场人物）
- 动作描写：以 `▲` 开头，每行一个动作；四要求=可视化/感官化/具体化/以动写情
- 台词：角色名 + 冒号 + 台词内容；无动作标注包裹时保持口语化

## 四、台词排版
- 超 3 行台词视为冗长，拆分或删减
- 潜台词优先：说出口 1/8，暗流 7/8

## 五、终审前置检查（交付前对照）
- 场次是否有变化（信息/关系/情感/认知/局势）
- 钩子/悬念是否收束；承诺/核心台词是否已埋线
- 道具同一性与状态过渡（错题本 E-04/E-12）
- 情绪词是否解释式（红线一）；意象是否重复（红线三）
