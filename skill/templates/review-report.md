# 审核报告模板

> 监察者/审核工作流输出标准。先审核后修改，报告与修改分离。

## 审核报告结构

```markdown
# 审核报告：{作品名}（{类型}）
审核维度：{七维/六维/导演标准/完结三维}
审核时间：{ISO8601}

## 1. 总评
- 通过状态：{通过 / 有条件通过 / 不通过}
- 一句话总评

## 2. 问题清单（按严重级排序）

### 🔴 致命（必须修改）
- 【维度】{问题描述}
  - 证据：{场次/行号/引用原文}
  - 建议：{修改方向}
  - 关联：{错题本 E-XX / 红线 X / 门控 X}

### 🟡 损伤（强烈建议修改）
- （同上结构）

### 🟢 注意（可选优化）
- （同上结构）

## 3. 各维度分评
{维度}：{达标情况 + 主要问题}

## 4. 修改优先级建议
1. {先改什么（结构→人物→场景→台词→格式）}
2. ...

## 5. 复核说明
- 是否对照错题本复查：{是/否，命中条目}
- 防回退核查：{已修正问题是否回退}
```

## 输出铁律
1. 逐问题给证据与建议，禁止只给结论不给位置。
2. 不改写用户原文；报告与修改分离。
3. 关键台词/道具/逻辑问题先查错题本再下结论。
4. 终审量化（精品剧）：逻辑错误=0；违背人设≤3%；冗余场景≤5%。
