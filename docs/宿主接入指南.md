# 宿主接入指南（所有智能体通用化）

> QNjbzj 不再绑定 WorkBuddy。本指南说明如何在任意智能体宿主（WorkBuddy / 本 Agent / 其他 Agent / 通用编排框架）中装载并运行本专家。

## 一、通用化设计原则
1. **知识层（skill/）= 纯文本协议**：不依赖任何宿主 API，任何能读 Markdown 的智能体均可装载。
2. **机制层（qn/ + runtime/ + heartbeat/ + regression/ + evolution/）= 宿主无关代码**：纯 Python 标准库（可选 numpy/requests），跨平台。
3. **大脑层可插拔**：创作/审核推理可以来自宿主模型、外部 LLM（本地 Ollama 或任意 OpenAI 兼容端点）、或宿主 Agent 自身推理（tool-assisted）。
4. **数据层（data/）自包含**：记忆/错题/锚点/日志全部在工程 data/ 下追加式落盘，跨会话复用；有宿主原生记忆时映射到宿主命名空间。

## 二、三种大脑模式（brain mode）
| 模式 | 使用方 | 说明 |
|---|---|---|
| host-brain | WorkBuddy 等原生带 LLM 的宿主 | 宿主模型直接充当主笔/监察者，按 skill/ 协议执行，本工程提供协议与流程 |
| local-llm | 本地有 Ollama 等的环境 | 通过 tools/llm_client.py 调 http://127.0.0.1:11434/v1（qwen2.5:14b 等）执行创作/审核 |
| tool-assisted | 无模型但有 exec 的宿主 | 本 Agent/其他 Agent 自身推理 + 工具化校验（错题断言/记忆检索/心跳/回归） |

**多宿主通用落法**：同一份 skill/ 知识打包成一段可装载指令（SKILL.md 作为总纲，按 references/00_overview 索引按需加载 references），任何 Agent 收到该指令即成为"QNjbzj 专家"；工程代码作为其可选工具/脚本执行层。

## 三、装载清单（给任意宿主的一条指令）
> 把下面这段发给目标 Agent，即可让 TA 拥有全能剧本专家能力（示例，可按宿主微调）：

```
你是全能剧本专家（技能代号 QNjbzj）。请先阅读 D:\D_AIdirector\QNjbzj\skill\SKILL.md
了解八机制协议与六角色体系，再按 skill\references\00_overview.md 的索引按需加载
references（创作走 01/02/03/10/11/12/13，审核走 04/08，记忆维护走 05/06/07）。
执行创作时你扮演总导演编排六个角色，交付前必须用错题本 E-01~E-13 与审美门控自检。
如宿主可执行 Python，可调用工程 tools\ 下脚本做机器校验：
  - tools\errorbook_check.py check "文本"   # 错题断言
  - tools\heartbeat.py                       # 心跳自检
  - tools\memory_store.py add|search         # 只增记忆
  - tools\llm_client.py chat "..."           # 本地 LLM 调用（可选）
```

## 四、与宿主原生命令的优先级
1. 宿主自身能力可闭环时，宿主优先（host-brain）。
2. 需要机器校验/确定性断言时，用工程 tools/（tool-assisted）。
3. 宿主不可用模型且本地有 Ollama 时，走 local-llm。
