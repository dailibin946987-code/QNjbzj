# 缺口解决方案

> 对应《剧本知识学习报告》§四综合结论：**必须自建（缺口集中区）= Agent 运行时进程框架、心跳执行器、自动化回归验证、全自动进化安全护栏**。
> 本方案把四缺口在 QNjbzj 工程内逐一落地为可运行实现。记忆层/自动学习/自我纠错闭环/错题本思路等"可直接照搬"资产，通过接口对接而非重写。

## 缺口 1：Agent 运行时进程框架（把"文档化角色"实例化为可调度 Agent）

**问题**：skill-evo-team 的四层架构（主脑/监察者/套装大脑/技能）是文档化角色 + 编排协议，无进程级运行时；"强制监察使触发"靠提示词自觉，不具运行时强制力。

**方案**（`qn/runtime/`）：
- `Agent` 基类：一个技能/角色 = 一个 Agent 实例。生命周期 = REGISTERED -> STARTED -> RUNNING -> STOPPED；提供 `on_message()`（处理总线消息）、`check()`（供心跳探活）、`run_task()`（执行主任务）。
- `Supervisor`：进程框架。负责 注册/启动/停止、心跳看板（team_health: active/degraded/offline）、超时自动拉起、任务失败隔离。
- 总线消息沿用 skill-evo-team schema：`{header:{type,from,to,routing_key}, body:{...}, trace:{...}}`，heartbeat 走 `team.heartbeat` 路由。
- 强制机制落地：Supervisor 在每次 Agent 输出后主动触发 `inspector`（监察）回调链，而不是依赖 Agent 自觉。

## 缺口 2：心跳执行器（周期发送 / 超时判定 / 自动恢复）

**问题**：套装只有 heartbeat 消息类型与 skills_online/degraded/offline 数据模型，无周期发送/超时/拉起实现。

**方案**（`qn/heartbeat/executor.py`）：
- 心跳循环线程：按 `interval` 周期向所有在线 Agent 发 `ping`（可挂 `on_ping` 探活回调），记录 last_seen。
- 超时判定：超过 `missed_threshold` 次未应答 -> 状态降级 `degraded`；超过 `down_threshold` -> 置 `offline` 并通知 Supervisor 拉起。
- 恢复重放：Agent 被拉起后，缓存期内未确认的 `team.heartbeat`/任务消息按序重放，避免丢消息。
- 全程写 `data/logs/heartbeat.log`（JSON 行），供审计。

## 缺口 3：自动化回归验证（把错题本从"文档核查"变为"可执行检查"）

**问题**：锚点/错题本（LY_JBKF-SH E-01~E-13）靠每次执行时人工/提示词核查，错误可能漏检，"同样错误不出现 2 次"缺运行时保障。

**方案**（`qn/regression/runner.py` + `tests/cases/*.yaml`）：
- 回归用例 = 错题本的机器可读形态：`id / error_pattern（不该出现的文本/结构模式，正则或子串） / required_pattern（应出现的关键点） / 审核要点说明`。
- Runner 输入为"某次技能产出"（文本或结构化 JSON），逐条断言：**错题模式不得命中、必须要点必须命中**。
- 产物：回归报告（用例级 pass/fail + 失败详情）。作为**进化护栏的验收闸**、以及每次技能升级后自动跑的防回退测试。
- tests/cases 中提供 E-01~E-13 的代表性子集样例，实际生产可全量扩展。

## 缺口 4：全自动进化的安全护栏（替代"人工确认 diff"）

**问题**：self-improving 三级自精炼 Step 3 要求**用户确认 diff**。若全能剧本专家要求全自动进化，需把"人工确认"替换为"沙箱验证 + 灰度上线 + 快照回滚"，且保留审计。

**方案**（`qn/evolution/guardrails.py`）：
- 快照：进化前对受影响的技能文档/规则做不可变快照（data/snapshots/<skill>-<ts>.bak），记录 old_hash。
- 沙箱验证：新规则先在隔离上下文跑回归 + 样例执行，计算指标（regression_pass_rate、样例成功率）。
- 灰度：指标达标才进入灰度（可配置灰度比例/试用范围），灰度期间持续统计。
- 门禁：`regression_pass_rate < 1.0`（错题本不允许任何一条复发）或样例成功率回退 -> **阻断并自动回滚**到快照；否则晋升正式并写 evolution_log。
- 与"记忆只增不迭代"的关系：经验/错误层（data/errors、data/anchors）只追加；技能规则层受控进化但快照留痕、审计可回滚（对应报告 §四矛盾点对齐）。
